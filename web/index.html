OrgCortex — Org-Scale Semantic Graph, Infinite-Context Factoring Meta-Agent & Agent Observability

Automatically discovers typed causal relationships (BLOCKS, SUPERSEDES_RFC, ROOT_CAUSED_BY_PR, OWNED_BY_TEAM, IMPACTS_OKR) across Slack war-rooms, SIM incidents, Git PRs, Architecture RFCs, and Quarterly OKRs—enforcing pre-traversal team-scope governance before paging context through an L1 / L2 / L3 Semantic Page Table for live Amazon Bedrock (us.amazon.nova-lite-v1:0) synthesis.

📖 In Plain English — What OrgCortex Does in 20 Seconds

In a large engineering organization, the real answer to "Why is our checkout launch on hold, and what fixed it?" never lives in one file: the launch hold is in a SIM ticket, the root-cause flamegraph is in a Slack war-room, the bug is in a Git Pull Request, the fix follows a newer Architecture RFC that quietly replaced an older 2024 RFC, and the dollar impact sits in a Quarterly OKR ledger. Standard search misses hops that use different words, while dumping every raw chat log and git diff into a huge prompt wastes ~9x tokens and tricks the LLM into citing outdated RFCs. OrgCortex links those five silos into a governed graph, checks which teams you are allowed to see before walking the graph, and acts like an operating-system virtual memory manager—keeping only crisp active evidence in L1, short multi-hop summaries in L2, and evicting obsolete RFCs and noisy diffs to zero-token L3 pointers.

§01 · Problem Statement

Why Enterprise Multi-Silo Search & Raw Context Stuffing Break Down

Organizational context constantly mutates across chat threads, tickets, pull requests, design docs, and business ledgers—exposing three empirical failure modes that we measured live against Amazon Bedrock Nova Lite.

Measured Across 16 Queries × 3 Pipelines
FAILURE MODE 01 · VOCABULARY DISCONNECT

Single-Hop RAG Misses Downstream Causal Hops

When an engineer asks why "Express Wallet GA" is on hold, keyword/vector search matches the release ticket (SIM-48305) and even frontend button CSS commits (PR-9105), but completely misses the DynamoDB lock-scan PR (PR-9412) three hops away because that PR never mentions "Express Wallet." In our live Bedrock benchmark, Top-2 RAG achieved only 78.1% (50/64) recall.

FAILURE MODE 02 · STALE RFC POLLUTION

Chronological Stuffing Suffers Context Rot

Real 2024–2025 architecture docs (RFC-084, RFC-112, RFC-120) keep their authoritative titles even after a newer 2026 RFC supersedes them. Stuffing the entire authorized archive chronologically burned 9,425 mean Bedrock inputTokens per query and dropped to 87.5% on Supersession Hygiene and 81.2% on Cross-Team Blocker questions.

FAILURE MODE 03 · TRANSITIVE ACL DRIFT

Post-Retrieval Filtering Risks Cross-Team Leaks

In an interconnected enterprise graph, a shared product OKR can sit one or two edges from restricted executive HSM incidents (SIM-52900, $9.2M regulated banking ARR) or PCI war-rooms (SLACK-WAR-771). Governance boundaries must be enforced prior to graph traversal and summary factoring so unauthorized facts never enter working memory.

§02 · System Architecture

End-to-End System Architecture (Serverless Edge → 5 Silos → Governed Graph → L1/L2/L3 Pager → Bedrock)

Five-plane serverless architecture deployed on Amazon CloudFront, Private S3 (SigV4 OAC), Python 3.12 AWS Lambda, and Amazon Bedrock Nova Lite. Click any component in the diagram or pill bar below to inspect its module contract and measured telemetry.

STEP 01 · SEMANTIC FABRIC

5-Silo Relationship Discovery

Extracts explicit causal clauses and domain token cosine links across Slack, SIM, Git PRs, RFCs, and OKRs to build directed BLOCKS, SUPERSEDES_RFC, ROOT_CAUSED_BY_PR, OWNED_BY_TEAM, and IMPACTS_OKR edges.

STEP 02 · AWS CONTEXT GATE

Pre-Traversal Team-ACL Filter

Enforces caller role_team permissions before BM25 scoring or multi-hop graph expansion, short-circuiting restricted entity probes in 0.4–1.0 ms with zero LLM calls and 0.0% data leakage.

STEP 03 · PAGE TABLE FACTORING

L1 / L2 / L3 Context Manager

Strips raw diffs and JSON blobs for L1 Working Set, compresses intermediate hops into entity/metric L2 Propositions, and evicts obsolete RFCs into 0-token L3 Cold Pointers (ctx://).

STEP 04 · NOVA + OTEL JUDGE

Cited Synthesis & Span Rubric

Calls us.amazon.nova-lite-v1:0 via boto3 converse() over factored pages, then runs GroundingJudge to score citation precision, supersession hygiene, and W3C OpenTelemetry spans.

SUBSYSTEM 01 · CROSS-SILO RELATIONSHIP DISCOVERY & SUPERSESSION PROPAGATION org_cortex/semantic_fabric.py :: _discover_edges_for_single_artifact()
Plain-English Intuition

Turning Scattered Mentions Into Directional Cause-and-Effect

Engineers naturally write causal breadcrumbs across tools—a Slack message says "bisected SIM-48291 to PR-9412," a release ticket says "blocked by SIM-48291," and a new architecture doc says "this specification supersedes RFC-084." OrgCortex reads those directional cues as soon as an artifact arrives, wiring up a live causal map and automatically flagging replaced RFCs as obsolete even if nobody edited the old document's title.

Under the Hood

Clause-Scoped Regex Windows + Cosine Cross-Silo Linker

ENTITY_ID_RE locates typed identifiers (PR-\d+, SIM-\d+, RFC-\d+, OKR-*, SLACK-*) and inspects a narrow 48-character pre-clause to disambiguate X blocks Y vs Y blocked by X, and active supersedes RFC-* clauses vs passive mentions. When SUPERSEDES_RFC registers, _register_edge() mutates target.status = "SUPERSEDED" and superseded_by = source_id. Custom ingested artifacts without explicit IDs fall back to shared-ACL normalized token cosine similarity (threshold ≥ 0.20, minimum 4 shared domain terms).

SUBSYSTEM 02 · INFINITE-CONTEXT FACTORING META-AGENT (SEMANTIC PAGE TABLE) org_cortex/semantic_fabric.py :: AdaptiveContextManager.factor_context()
Plain-English Intuition

Virtual Memory Paging for LLM Prompts

Humans investigating an outage don't paste 500 lines of CSS diffs and closed APAC tickets into their working thoughts—they keep the 2 primary tickets open in front of them, jot down 1-line bullet notes for the 4 related PRs and RFCs, and close obsolete docs while remembering where to find them. AdaptiveContextManager gives the LLM that exact three-level memory hierarchy inside any user-chosen token budget.

Under the Hood

Boilerplate Stripping, L2 Propositions & SHA-256 ctx:// Pointers

Reserves 260 tokens for instruction framing, allocating 44% of usable budget to L1 (strip_boilerplate_for_l1() strips fenced unified diffs, JSON alarm payloads, and bot lines) and 56% to L2 (build_l2_factored_proposition() preserves extracted METRIC_EXTRACT_RE figures and incident graph edges). Any artifact with status == "SUPERSEDED" or low salience is evicted to L3 as ctx://org-cortex/<silo>/<id>#<sha256[:10]> at 0 prompt tokens—cutting measured Bedrock inputTokens by -88.1% (8.38x).

SUBSYSTEM 03 · AWS CONTEXT PRE-TRAVERSAL ACL GATE & 5-AGENT OTEL WATERFALL org_cortex/semantic_fabric.py + server.py :: _traverse_governed_subgraph() & reason()
Plain-English Intuition

Locking Restricted Doors Before the Scout Starts Walking

Instead of letting an agent traverse the entire company graph and hoping a final filter catches secrets, GraphScout removes unauthorized team rooms from the map before taking Step 1. And if someone explicitly asks about a restricted ticket ID outside their scope, OrgCortex immediately declines in under a millisecond without even waking up the LLM. Every step is timed and graded so operators can see why an answer was produced.

Under the Hood

Set-Intersection ACL Pre-Filter + time.perf_counter() Spans

Computes set(policy["allowed_teams"]) & set(artifact.team_acl) prior to building adjacency lists; if explicit_unauthorized_hit and not authorized_explicit, short-circuits in 0.4–1.0 ms (0 Bedrock tokens, 0.0% leakage across all 16 benchmark queries). Wraps Planner, GraphScout, ContextFactorer, Synthesizer (boto3.client("bedrock-runtime").converse()), and GroundingJudge in parent-linked W3C span records with exact inputTokens/outputTokens telemetry.

§04 · Design Tradeoffs

Architectural Decisions, Alternatives & Empirical Tradeoffs

Every engineering mechanism trades off one resource to win on accuracy, latency, cost, or security isolation—quantified below from our live AWS Bedrock benchmark.

Design Dimension OrgCortex Mechanism Alternative Considered Measured Engineering Tradeoff
Prompt Memory Layout 3-Tier L1/L2/L3 Semantic Page Table Chronological Full-Archive Stuffing Reduces mean Bedrock inputTokens by -88.1% (1,125 vs 9,425 tok, 8.38x) and p50 e2e latency by -13.2% (2205.7 ms vs 2542.0 ms) while raising fact recall from 90.6% → 98.4%; L2 drops line-by-line code diff context when exact diff line numbers aren't requested.
Cross-Silo Candidate Recall BM25 Seeds + 4-Hop Typed Edge Spreading Activation Single-Hop Top-2 Lexical RAG Spends ~603 more input tokens than Top-2 RAG (1,125 vs 522) plus 2.389 ms p50 Python graph/paging CPU time, in exchange for lifting multi-hop recall from 78.1% → 98.4% (+20.3 pts).
Relationship Extraction Deterministic Clause Window + Shared-ACL Cosine Linker LLM Graph Extraction on Every Slack/PR Event Achieves < 2 ms synchronous ingestion at $0 LLM ingest cost; trades open-vocabulary relation invention for 5 high-precision enterprise schemas (BLOCKS, SUPERSEDES_RFC, ROOT_CAUSED_BY_PR, OWNED_BY_TEAM, IMPACTS_OKR).
Multi-Tenant Governance Pre-Traversal Team-ACL Subgraph Isolation Post-Retrieval Prompt Redaction / Judge Filter Guarantees 0.0% unauthorized leakage and 0.4–1.0 ms deterministic abstention on restricted probes; requires connectors to populate team_acl scopes at ingest time.
